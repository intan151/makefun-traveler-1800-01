One deterministic Python program (standard library only) writes one sentence
— 128 characters — explaining the modern internet to a traveler from 1800,
using only things a person from 1800 already knows, to `/output/entry.txt`.

> Picture a road joining every library and post office on earth, so a letter
> sent from your desk is answered before the ink dries.

Run it:

```sh
python3 main.py
```

It writes a single line of text to `/output/entry.txt`.
